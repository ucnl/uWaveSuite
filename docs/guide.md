# uWaveSuite — Руководство

## Подключение

1. Подключите модем через USB-UART
2. Откройте uWaveSuite
3. Нажмите **🔌 uWave**
4. Выберите COM-порт (обычно 9600 бод)
5. Приложение отправит DINFO запрос и определит устройство

## Настройка CDMA каналов

В **Настройки → Устройство**:
- TX канал — канал передачи
- RX канал — канал приема
- Солёность — для расчета скорости звука

При подключении настройки отправляются автоматически.

## Трекинг

### CDMA режим
- Устройства адресуются по паре (Tx, Rx) каналов
- Короткие запросы: ping, depth, temp, voltage

### Логический режим
- Устройства адресуются по адресу (0-254)
- 255 — широковещательный (без ответа)
- Работает поверх CDMA каналов

### Режимы команд
- **Взвешенный (5:1:1)** — глубина 5 раз, температура/напряжение по 1 разу
- **Циклический** — равномерно
- **Одиночный** — одна команда

## USBL

USBL устройство определяется по наличию азимута в ответе.
Для расчета позиции используется:
- Азимут (горизонтальный угол)
- Дальность (по времени распространения)
- Глубина (для проекции наклонной дальности)

## VLBL

Режим дальномерной навигации:
1. Добавьте базы (неподвижные модемы)
2. Включите автосбор
3. Плавайте вокруг баз — измерения собираются автоматически
4. Система решает задачу TOA и определяет координаты баз

## Экспорт

- **CSV** — таблица измерений
- **KML** — для Google Earth
- **JSON** — полные данные
- **NMEA GGA** — стандартные предложения
- **DXF** — для CAD
