# Changelog

## [0.2.0] - 2026-09-14

### Added
- PWA-оболочка: манифест (`manifest.json`) и Service Worker (`sw.js`) — приложение можно установить как standalone-приложение на десктопе (Chrome, Edge)
- Автоматическое обновление через Service Worker: `skipWaiting()` и `clients.claim()` — новая версия применяется при следующем запуске приложения
- Иконки приложения (192×192, 512×512)

### Changed
- Service Worker регистрируется только в защищённом контексте (http/https). Работа из `file://` и из Android Launcher не затронута
- Кэширование статики не влияет на работу Web Serial API (serial работает напрямую с USB, минуя сеть)

### Notes
- В standalone-режиме Vivaldi диалог выбора порта Web Serial может не отображаться — это известный баг браузера (подтверждён в трекере Vivaldi). В Chrome и Edge standalone работает корректно



## [0.1.0] - 2026-09-09

### Добавлено
- Первый релиз uWaveSuite
- Подключение к модему uWave (Web Serial)
- Протокол uWave (NMEA $PUWV)
- Трекинг устройств (CDMA + Logical)
- Взвешенный режим команд (5:1:1)
- USBL решение (азимут + дальность)
- VLBL решатель (TOA)
- Карта с устройствами и треками
- Линейка и графическая шкала
- Топопривязка
- Логирование NMEA
- Воспроизведение логов
- Экспорт CSV, KML, JSON, GGA, DXF
- Темы оформления (6 тем)
- Ручные запросы (CDMA + пакетные)

### Техническое
- Плоская структура JS
- Event-driven архитектура
- Promise-based порт
- Модульная система UI
